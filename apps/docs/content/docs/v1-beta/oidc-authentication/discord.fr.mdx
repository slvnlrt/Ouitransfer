Discord est l'un des fournisseurs OIDC officiellement pris en charge par OUITRANSFER. Il offre une authentification sécurisée via Discord OAuth 2.0. Cette intégration permet aux utilisateurs de se connecter à OUITRANSFER avec leur compte Discord existant, ce qui en fait une solution idéale pour les communautés de jeux, les équipes de développement et les organisations utilisant déjà Discord.

<ZoomableImage src="/assets/v1/oidc/discord/sign-in-with-discord.png" alt="Se connecter avec Discord" />

## Pourquoi utiliser l'authentification Discord ?

L'authentification Discord présente plusieurs avantages pour les organisations et équipes axées sur la communauté :

- **Intégration communautaire** - Idéal pour les communautés de jeux et les organisations centrées sur Discord
- **Expérience familière** - Les utilisateurs font déjà confiance à Discord et l'utilisent au quotidien
- **Profils utilisateurs enrichis** - Accès aux noms d'utilisateur Discord, aux avatars et aux noms globaux
- **Convivial pour les développeurs** - Parfait pour les équipes techniques et les projets open source
- **Pas de compte supplémentaire** - Les utilisateurs accèdent à OUITRANSFER sans créer de nouveaux identifiants

---

## Prérequis

Avant de configurer l'authentification Discord, assurez-vous de disposer des éléments suivants :

- **Accès au Discord Developer Portal** - Capacité à créer des applications sur Discord
- **Privilèges administrateur dans OUITRANSFER** - Requis pour configurer les paramètres OIDC
- **Propriété du serveur ou permissions** - Si vous intégrez un serveur Discord

> **Remarque :** Discord est préconfiguré en tant que fournisseur officiel dans OUITRANSFER, ce qui signifie que la configuration technique est gérée automatiquement. Vous devez uniquement fournir vos identifiants OAuth.

---

## Configurer le Discord Developer Portal

### Créer une application Discord

Pour démarrer avec l'authentification Discord, vous devez créer une application dans le Discord Developer Portal.

1. **Accéder au Discord Developer Portal** : Rendez-vous sur [discord.com/developers/applications](https://discord.com/developers/applications)

<ZoomableImage src="/assets/v1/oidc/discord/developer-portal-home.png" alt="Accueil du Discord Developer Portal" />

2. **Créer une nouvelle application** : Cliquez sur le bouton **"New Application"**
3. **Saisir les informations de l'application** :
   - **Name** : Saisissez un nom descriptif comme « OUITRANSFER File Sharing »
   - **Accept Terms of Service and Developer Policy** : Cochez la case

<ZoomableImage src="/assets/v1/oidc/discord/create-application-modal.png" alt="Fenêtre de création d'application Discord" />

4. **Créer l'application** : Cliquez sur **"Create"** pour générer votre application

### Configurer les paramètres de l'application

Après avoir créé votre application, vous devez configurer les paramètres de base et l'identité visuelle.

1. **Mettre à jour les informations de l'application** :
   - **Description** : Ajoutez une description claire de votre instance OUITRANSFER
   - **Icon** : Téléversez le logo de votre organisation ou une icône liée à OUITRANSFER
   - **Cover Image** : Image de bannière optionnelle pour améliorer l'identité visuelle

<ZoomableImage
  src="/assets/v1/oidc/discord/application-settings.png"
  alt="Paramètres de l'application Discord"
  legend="Il s'agit d'une application fictive, vous devez utiliser la vôtre."
/>

2. **Configurer les détails de l'application** :
   - **Tags** : Ajoutez des tags pertinents (optionnel)
   - **Privacy Policy URL** : Ajoutez l'URL de votre politique de confidentialité si nécessaire
   - **Terms of Service URL** : Ajoutez l'URL de vos conditions d'utilisation si nécessaire

### Configurer OAuth2

Vous allez maintenant configurer les paramètres OAuth2 que OUITRANSFER utilisera pour authentifier les utilisateurs.

1. **Accéder à OAuth2** : Dans la barre latérale gauche, cliquez sur **"OAuth2"**

<ZoomableImage src="/assets/v1/oidc/discord/oauth2-general.png" alt="Paramètres généraux OAuth2 de Discord" />

2. **Configurer les paramètres OAuth2** :
   - **Client Secret** : Cliquez sur **"Reset Secret"** pour générer un nouveau secret client
   - **Copier les identifiants** : Enregistrez le **Client ID** et le **Client Secret** pour une utilisation ultérieure

3. **Ajouter les URI de redirection** : Dans la section **"Redirects"**, ajoutez les URL de rappel OUITRANSFER :

Vous devez configurer plusieurs URL dans les paramètres de votre application Discord. Voici ce qu'il faut ajouter pour chaque environnement :

### URI de redirection

| Environnement | URL                                                               |
| ------------- | ----------------------------------------------------------------- |
| Production    | `https://yourdomain.com/api/auth/providers/discord/callback`      |
| Développement | `http://localhost:3000/api/auth/providers/discord/callback`       |
| Port personnalisé | `https://yourdomain.com:5487/api/auth/providers/discord/callback` |

> **Remarque :** Remplacez `yourdomain.com` par votre nom de domaine réel dans toutes les URL de production et de port personnalisé.
> **Remarque :** Vous pouvez ajouter plusieurs URI de redirection pour différents environnements (développement, pré-production, production).

4. **Sélectionner les scopes requis** :
   - **`identify`** - Accès aux informations de base du compte de l'utilisateur (requis)
   - **`email`** - Accès à l'adresse e-mail de l'utilisateur (requis pour OUITRANSFER)

5. **Enregistrer les modifications** : Cliquez sur **"Save Changes"** pour appliquer votre configuration

## Configurer OUITRANSFER

### Accéder aux paramètres OIDC

Pour configurer l'authentification Discord dans OUITRANSFER, vous devez disposer d'un accès administrateur au panneau de paramètres.

1. **Se connecter en tant qu'administrateur** : Connectez-vous à OUITRANSFER avec un compte administrateur

2. **Accéder aux paramètres** : Cliquez sur votre photo de profil dans l'en-tête et sélectionnez **Settings**

3. **Accéder à l'authentification** : Trouvez et cliquez sur la section de configuration **Authentication Providers**

<ZoomableImage src="/assets/v1/oidc/auth-providers.png" alt="Fournisseurs d'authentification OUITRANSFER" />

### Activer le fournisseur Discord

Discord est préconfiguré en tant que fournisseur officiel, ce qui simplifie le processus de configuration.

1. **Localiser le fournisseur Discord** : Trouvez Discord dans la liste des fournisseurs disponibles

2. **Activer le fournisseur** : Basculez le statut sur **Enabled**

<ZoomableImage src="/assets/v1/oidc/discord/OUITRANSFER-enabled-discord.png" alt="Fournisseur Discord OUITRANSFER activé" />

Après avoir activé le fournisseur, cliquez sur l'icône de crayon pour le configurer.

3. **Configurer les identifiants** :
   - **Client ID** : Collez le Client ID provenant du Discord Developer Portal
   - **Client Secret** : Collez le Client Secret provenant du Discord Developer Portal
   - **Scopes** : Ajoutez les scopes que vous souhaitez utiliser. Les scopes par défaut sont `identify` et `email`.

<ZoomableImage
  src="/assets/v1/oidc/discord/edit-discord.png"
  alt="Modifier le fournisseur Discord"
  legend="Il s'agit d'une application fictive, vous devez utiliser la vôtre."
/>

### Options de configuration avancées

Configurez des paramètres supplémentaires pour personnaliser le comportement de l'authentification :

**Auto Registration** : Activez cette option pour créer automatiquement des comptes utilisateurs lors de la première authentification.

**Admin Email Domains** : Spécifiez les domaines qui doivent recevoir automatiquement des privilèges administrateur. Cette option est moins courante avec Discord car les utilisateurs utilisent souvent des adresses e-mail personnelles.

**Sort Order** : Contrôlez l'ordre d'affichage du bouton de connexion Discord par rapport aux autres fournisseurs d'authentification.

**Icon** : vous pouvez choisir l'icône à utiliser pour le bouton de connexion Discord (par défaut : `FaDiscord`).

<ZoomableImage src="/assets/v1/oidc/discord/discord-icon.png" alt="Icône Discord" />

> **Conseil communautaire :** L'authentification Discord convient parfaitement aux communautés de jeux et aux équipes de développement. Envisagez d'activer l'inscription automatique pour les communautés Discord de confiance.

## Liaison de comptes

Par défaut, si un utilisateur est déjà inscrit dans OUITRANSFER avec son adresse e-mail Discord, il sera automatiquement lié à son compte OUITRANSFER.

> **Remarque :** Il n'est pas possible de désactiver la liaison de comptes. Si vous souhaitez dissocier un utilisateur de son compte Discord, vous devez supprimer l'utilisateur dans OUITRANSFER.

---

## Configuration technique

La configuration technique de Discord est gérée automatiquement, mais comprendre cette configuration peut aider au dépannage :

```yaml
Provider Type: OAuth 2.0 (No OIDC Discovery)
Issuer URL: https://discord.com
Authorization Endpoint: /oauth2/authorize
Token Endpoint: /api/oauth2/token
UserInfo Endpoint: /api/users/@me
Scopes: identify email
```

### Correspondances de champs

OUITRANSFER mappe automatiquement les informations utilisateur Discord vers les comptes utilisateurs locaux :

- **User ID** : Correspond au champ `id` de Discord
- **Email** : Correspond au champ `email` de Discord
- **Display Name** : Correspond au champ `global_name` de Discord ou au champ `username` par défaut
- **Username** : Correspond au champ `username` de Discord
- **Avatar** : Correspond au champ `avatar` de Discord (traité comme URL Discord CDN)

### Fonctionnalités spécifiques à Discord

- **Noms globaux** : Prend en charge le nouveau système de noms globaux de Discord tout en maintenant la compatibilité avec les noms d'utilisateur hérités
- **Traitement des avatars** : Construit automatiquement les URL Discord CDN pour les avatars des utilisateurs
- **Sans découverte** : Utilise des points de terminaison configurés manuellement pour une meilleure fiabilité

## Tester la configuration

### Vérifier la configuration

Après avoir configuré l'authentification Discord, testez l'intégration pour vous assurer que tout fonctionne correctement.

1. **Vérifier la page de connexion** : Accédez à la page de connexion de OUITRANSFER et vérifiez que le bouton « Sign in with Discord » s'affiche

2. **Tester le flux d'authentification** : Cliquez sur le bouton de connexion Discord et complétez le processus d'authentification

3. **Vérifier la création de l'utilisateur** : Confirmez qu'un nouveau compte utilisateur est créé (si l'inscription automatique est activée)

### Vérification du flux de connexion

Le processus d'authentification complet doit fonctionner comme suit :

1. **L'utilisateur clique sur « Sign in with Discord »** : Le navigateur est redirigé vers la page d'autorisation de Discord
2. **L'utilisateur autorise l'application** : L'utilisateur accorde les permissions pour les scopes `identify` et `email`
3. **Discord redirige vers OUITRANSFER** : L'utilisateur revient sur OUITRANSFER avec les jetons d'authentification
4. **OUITRANSFER crée ou met à jour l'utilisateur** : Le compte utilisateur est automatiquement géré avec les informations Discord
5. **L'utilisateur accède à OUITRANSFER** : L'utilisateur est connecté avec son identité Discord

## Résolution des problèmes courants

### Erreur d'URI de redirection invalide

**Message d'erreur** : `invalid_redirect_uri`

**Cause** : L'URI de redirection dans votre requête ne correspond pas à celle configurée dans le Discord Developer Portal.

**Solution** :

1. Vérifiez l'URL exacte dans le message d'erreur
2. Ajoutez cette URL exacte dans les URI de redirection de votre application Discord
3. Assurez-vous d'inclure le bon protocole (http/https) et le bon port
4. Supprimez les barres obliques de fin sauf si elles figurent dans l'URL de rappel

### Erreur d'accès refusé

**Message d'erreur** : `access_denied`

**Cause** : L'utilisateur a refusé les permissions ou l'application ne dispose pas des scopes requis.

**Solution** :

1. Vérifiez que votre application Discord demande les scopes `identify` et `email`
2. Vérifiez que les utilisateurs accordent les permissions pendant le flux d'autorisation
3. Assurez-vous que votre application n'est pas restreinte ou désactivée dans le Discord Developer Portal
4. Vérifiez que l'application dispose des permissions correctement configurées

### Erreur de client invalide

**Message d'erreur** : `invalid_client`

**Cause** : Client ID ou Client Secret incorrect.

**Solution** :

1. Vérifiez que vous avez correctement copié les identifiants depuis le Discord Developer Portal
2. Assurez-vous qu'il n'y a pas d'espaces ou de caractères supplémentaires dans les identifiants
3. Générez un nouveau Client Secret si nécessaire
4. Vérifiez que vous utilisez la bonne application dans le Discord Developer Portal

### Erreur de scope email manquant

**Message d'erreur** : E-mail non fourni ou scope manquant

**Cause** : L'application Discord n'est pas configurée avec le scope email ou l'adresse e-mail de l'utilisateur n'est pas vérifiée.

**Solution** :

1. Vérifiez que votre application Discord demande le scope `email`
2. Vérifiez que les utilisateurs ont vérifié leur adresse e-mail sur Discord
3. Assurez-vous que la configuration des scopes correspond à ce qu'OUITRANSFER attend
4. Testez avec un compte Discord dont l'adresse e-mail est vérifiée

### Informations utilisateur ne s'affichant pas correctement

**Cause** : Problèmes de correspondance entre le nom d'utilisateur Discord et le nom global.

**Solution** :

1. Vérifiez que l'utilisateur a défini un nom global dans Discord (nouvelle fonctionnalité)
2. Vérifiez que les correspondances de champs fonctionnent correctement dans les journaux OUITRANSFER
3. Testez avec différents comptes Discord (certains peuvent avoir des noms d'utilisateur hérités)
4. Mettez à jour manuellement les informations utilisateur via l'interface d'administration OUITRANSFER si nécessaire

## Bonnes pratiques de sécurité

### Gestion des identifiants

- **Ne jamais exposer les secrets** : Gardez votre Client Secret sécurisé et ne le committez jamais dans le contrôle de version
- **Rotation régulière des identifiants** : Générez de nouveaux Client Secrets périodiquement pour renforcer la sécurité
- **Utiliser des variables d'environnement** : Stockez les configurations sensibles dans des variables d'environnement, pas dans des fichiers de configuration
- **Surveiller les journaux d'accès** : Examinez régulièrement les journaux d'authentification pour détecter toute activité suspecte

### Gestion des scopes et des permissions

- **Scopes minimaux** : Demandez uniquement les scopes `identify` et `email` requis par OUITRANSFER
- **Consentement des utilisateurs** : Assurez-vous que les utilisateurs comprennent les permissions qu'ils accordent
- **Audits réguliers** : Vérifiez quels utilisateurs ont connecté leur compte Discord
- **Revues d'accès** : Examinez périodiquement les accès des utilisateurs et supprimez les comptes inactifs

### Considérations pour la production

- **Utiliser HTTPS** : Utilisez toujours HTTPS dans les environnements de production
- **Configurer les bons domaines** : Utilisez les domaines de production dans les URI de redirection Discord
- **Tester rigoureusement** : Vérifiez le flux d'authentification complet avant la mise en production
- **Prévoir les pannes** : Ayez des méthodes d'authentification de secours disponibles
