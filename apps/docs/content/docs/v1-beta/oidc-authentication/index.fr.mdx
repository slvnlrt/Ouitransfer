OUITRANSFER prend en charge l'authentification OpenID Connect (OIDC), permettant aux utilisateurs de se connecter via des fournisseurs d'identité externes tels que Google, Zitadel, Auth0 et tout autre service conforme à OIDC. Cette fonctionnalité offre des capacités d'authentification unique (SSO) transparentes et une gestion centralisée des utilisateurs.

L'authentification OIDC dans OUITRANSFER est construite sur le protocole standard OpenID Connect. L'implémentation prend en charge le provisionnement automatique des utilisateurs et des options de configuration flexibles.

## Pourquoi utiliser l'authentification OIDC ?

L'authentification OIDC présente plusieurs avantages pour les organisations et les utilisateurs :

**Authentification centralisée** : Les utilisateurs peuvent s'authentifier avec leurs identifiants organisationnels existants sans créer de comptes distincts pour OUITRANSFER

**Sécurité renforcée** : OIDC offre des fonctionnalités de sécurité robustes, notamment l'authentification par jeton, le flux PKCE et des protocoles standardisés.

**Authentification unique** : Les utilisateurs peuvent accéder à OUITRANSFER de manière transparente s'ils sont déjà authentifiés auprès de leur fournisseur d'identité.

**Gestion des utilisateurs** : Les administrateurs peuvent gérer les accès de manière centralisée via leur fournisseur d'identité existant.

**Conformité** : OIDC aide à satisfaire aux exigences de sécurité et de conformité organisationnelles en s'appuyant sur l'infrastructure d'identité existante.

## Prérequis

Avant de configurer l'authentification OIDC, assurez-vous de disposer des éléments suivants :

- **Accès administrateur** : Privilèges ADMIN dans OUITRANSFER pour configurer les paramètres OIDC
- **Fournisseur d'identité** : Un fournisseur d'identité conforme à OIDC (Google, Zitadel, Auth0, etc.)
- **Enregistrement de l'application** : Votre application OUITRANSFER enregistrée auprès de votre fournisseur d'identité
- **Identifiants OIDC** : Client ID, Client Secret et URL d'émetteur fournis par votre fournisseur d'identité

Dans cette documentation, vous pouvez consulter la procédure de configuration de chacun des fournisseurs officiels, ainsi qu'intégrer d'autres fournisseurs non listés comme officiels. ## Configurer les paramètres OIDC

La configuration OIDC est gérée via le panneau de paramètres administratifs d'OUITRANSFER, accessible uniquement aux utilisateurs disposant des privilèges ADMIN.

### Accéder à la configuration OIDC

Pour configurer l'authentification OIDC :

1. **Accéder aux paramètres** : Cliquez sur votre photo de profil dans l'en-tête et sélectionnez **Paramètres**
2. **Accéder à l'authentification** : Trouvez la section de configuration **Authentication Providers**
3. **Activer OIDC** : Activez l'option d'authentification OIDC

> **Remarque :** Consultez la documentation de chaque fournisseur pour le configurer.
