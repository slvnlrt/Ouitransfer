Pocket ID est l'un des fournisseurs OIDC officiellement pris en charge par OUITRANSFER, offrant une solution de gestion des identités robuste et flexible. Cette intégration permet aux utilisateurs de se connecter à OUITRANSFER grâce au système d'authentification Pocket ID, ce qui en fait une solution idéale pour les organisations souhaitant disposer d'un fournisseur d'identité auto-hébergé avec prise en charge d'OIDC.

<ZoomableImage src="/assets/v1/oidc/pocket-id/sign-in-with-pocket-id.png" alt="Connexion avec Pocket ID" />

## Pourquoi utiliser l'authentification Pocket ID ?

L'authentification Pocket ID présente plusieurs avantages pour les organisations à la recherche d'une solution d'identité auto-hébergée :

- **Contrôle total** - Maîtrise complète de votre infrastructure d'authentification et de vos données
- **Conformité OIDC** - Implémentation standard d'OpenID Connect pour une intégration transparente
- **Déploiement flexible** - Déployez sur toute infrastructure adaptée à vos besoins
- **Découverte automatique** - Prend en charge la découverte OIDC pour une configuration simplifiée
- **Configuration simple** - Processus de mise en place intuitif avec une complexité minimale
- **Souveraineté des données** - Conservez toutes les données d'authentification au sein de votre infrastructure
- **Rentabilité** - Sans tarification par utilisateur, idéal pour les organisations en croissance

---

## Prérequis

Avant de configurer l'authentification Pocket ID, assurez-vous de disposer des éléments suivants :

- **Instance Pocket ID** - Un serveur Pocket ID opérationnel, accessible via HTTPS
- **Privilèges administrateur dans OUITRANSFER** - Nécessaires pour configurer les paramètres OIDC
- **Configuration du domaine** - Pour les déploiements en production avec des domaines personnalisés

> **Remarque :** Pocket ID est préconfiguré comme fournisseur officiel dans OUITRANSFER, ce qui signifie que la configuration technique est gérée automatiquement. Vous n'avez qu'à fournir vos identifiants OAuth.

---

## Configuration de l'application Pocket ID

### Création d'une application Pocket ID

Pour démarrer avec l'authentification Pocket ID, vous devez créer une application dans l'interface d'administration de votre instance Pocket ID.

1. **Accédez à l'administration Pocket ID** : Rendez-vous sur l'URL de votre instance Pocket ID (ex. : `https://your-pocket-id.domain.com`)

<ZoomableImage src="/assets/v1/oidc/pocket-id/pocket-id-console.png" alt="Console Pocket ID" />

2. **Accéder aux clients OIDC** : Cliquez sur **"OIDC Clients"** dans les applications de la barre latérale gauche ; vous serez redirigé vers la page des clients OIDC

<ZoomableImage src="/assets/v1/oidc/pocket-id/oidc-clients.png" alt="Clients OIDC" />

3. **Créer un nouveau client OIDC** : Cliquez sur le bouton **"Add OIDC Client"** sur la page des clients OIDC

<ZoomableImage src="/assets/v1/oidc/pocket-id/create-oidc-client-button.png" alt="Bouton de création d'un client OIDC" />

Configurez les paramètres suivants :

- **Name** : "OUITRANSFER File Sharing" (ou le nom de votre choix)
- **Public Client** : "Disabled"
- **PKCE** : "Disabled"
- **Logo** : "Upload a logo image"

<ZoomableImage src="/assets/v1/oidc/pocket-id/create-oidc-client.png" alt="Création d'un client OIDC" />

### Configuration des URLs de l'application

Vous devez configurer plusieurs URLs dans les paramètres de votre application Pocket ID. Voici ce qu'il faut ajouter pour chaque environnement :

### URI de redirection

| Environnement     | URL                                                                |
| ----------------- | ------------------------------------------------------------------ |
| Production        | `https://yourdomain.com/api/auth/providers/pocketid/callback`      |
| Développement     | `http://localhost:3000/api/auth/providers/pocketid/callback`       |
| Port personnalisé | `https://yourdomain.com:5487/api/auth/providers/pocketid/callback` |

### URI de redirection après déconnexion

| Environnement     | URL                           |
| ----------------- | ----------------------------- |
| Production        | `https://yourdomain.com`      |
| Développement     | `http://localhost:3000`       |
| Port personnalisé | `https://yourdomain.com:5487` |

> **Remarque :** Remplacez `yourdomain.com` par votre nom de domaine réel dans toutes les URLs de production et de port personnalisé.
> **Remarque :** Vous pouvez ajouter plusieurs URI de redirection pour différents environnements (développement, recette, production).

<ZoomableImage src="/assets/v1/oidc/pocket-id/config-urls.png" alt="Configuration des URLs de l'application Pocket ID" />

### Récupération des identifiants OAuth

Après avoir créé votre application, vous obtiendrez vos identifiants OAuth :

<ZoomableImage

  alt="Identifiants OAuth Pocket ID"
  legend="Le Client ID et le Client Secret affichés dans l'image sont donnés à titre d'exemple uniquement (identifiants fictifs). Vous devez utiliser vos propres identifiants Pocket ID."

- Client ID

## Configuration d'OUITRANSFER

### Accès aux paramètres OIDC

Pour configurer l'authentification Pocket ID dans OUITRANSFER :

1. **Connexion en tant qu'administrateur** : Connectez-vous à OUITRANSFER avec un compte administrateur
2. **Accéder aux paramètres** : Cliquez sur votre photo de profil dans l'en-tête et sélectionnez **Settings**
3. **Accéder à l'authentification** : Recherchez et cliquez sur la section **Authentication Providers**

<ZoomableImage src="/assets/v1/oidc/auth-providers.png" alt="Fournisseurs d'authentification OUITRANSFER" />

### Activation du fournisseur Pocket ID

1. **Localiser Pocket ID** : Trouvez Pocket ID dans la liste des fournisseurs disponibles
2. **Activer le fournisseur** : Basculez le statut sur **Enabled**

<ZoomableImage src="/assets/v1/oidc/pocket-id/enabled-pocket-id.png" alt="Fournisseur Pocket ID activé dans OUITRANSFER" />

3. **Configurer les identifiants** :
   - **Provider URL** : L'URL de votre serveur Pocket ID (ex. : `https://auth.yourdomain.com`)
   - **Client ID** : Collez le Client ID de votre application Pocket ID
   - **Client Secret** : Collez le Client Secret de votre application Pocket ID

<ZoomableImage
  src="/assets/v1/oidc/pocket-id/edit-pocket-id.png"
  alt="Modifier le fournisseur Pocket ID"
  legend="Il s'agit d'une application fictive, vous devez utiliser vos propres identifiants."
/>

### Options de configuration avancées

Configurez des paramètres supplémentaires pour personnaliser le comportement de l'authentification :

**Auto Registration** : Activez cette option pour créer automatiquement des comptes utilisateurs lors de la première authentification.

**Sort Order** : Contrôlez la position du bouton de connexion Pocket ID par rapport aux autres fournisseurs d'authentification.

**Icon** : Choisissez une icône personnalisée pour le bouton de connexion Pocket ID (par défaut : `Key`).

<ZoomableImage src="/assets/v1/oidc/pocket-id/pocket-id-icon.png" alt="Icône Pocket ID" />

## Liaison de comptes

Par défaut, si un utilisateur est déjà inscrit dans OUITRANSFER avec son adresse e-mail Pocket ID, il sera automatiquement lié à son compte OUITRANSFER.

> **Remarque :** Vous ne pouvez pas désactiver la liaison de comptes. Si vous souhaitez dissocier un utilisateur de son compte Pocket ID, vous devez le supprimer d'OUITRANSFER.

---

## Configuration technique

La configuration technique de Pocket ID est gérée automatiquement via la découverte OIDC, mais comprendre la mise en place peut aider au dépannage :

```yaml
Provider Type: OAuth 2.0 with OIDC Discovery
Issuer URL: https://your-pocket-id.domain.com
Authorization Endpoint: /authorize
Token Endpoint: /api/oidc/token
UserInfo Endpoint: /api/oidc/userinfo
Scopes: openid profile email
```

### Correspondances de champs

OUITRANSFER mappe automatiquement les informations utilisateur Pocket ID vers les comptes utilisateurs locaux :

- **User ID** : Provient du champ `sub` de Pocket ID
- **Email** : Provient du champ `email` de Pocket ID
- **Name** : Provient du champ `name` de Pocket ID, avec repli sur `preferred_username`
- **First Name** : Provient du champ `given_name` de Pocket ID
- **Last Name** : Provient du champ `family_name` de Pocket ID
- **Avatar** : Provient du champ `picture` de Pocket ID

## Test de la configuration

### Vérification de la configuration

Après avoir configuré l'authentification Pocket ID, testez l'intégration :

1. **Vérifier la page de connexion** : Vérifiez que le bouton "Sign in with Pocket ID" apparaît
2. **Tester le flux d'authentification** : Cliquez sur le bouton et terminez le processus d'authentification
3. **Vérifier la création de l'utilisateur** : Confirmez la création d'un nouveau compte utilisateur (si l'inscription automatique est activée)

### Vérification du flux de connexion

Le processus d'authentification complet doit fonctionner comme suit :

1. L'utilisateur clique sur "Sign in with Pocket ID"
2. L'utilisateur est redirigé vers la page de connexion Pocket ID
3. L'utilisateur s'authentifie avec ses identifiants
4. Pocket ID redirige vers OUITRANSFER
5. OUITRANSFER crée ou met à jour le compte utilisateur
6. L'utilisateur accède à OUITRANSFER

## Résolution des problèmes courants

### Non-concordance de l'URI de redirection

**Erreur** : `invalid_redirect_uri`

**Solution** :

1. Vérifiez l'URL de rappel exacte dans votre application Pocket ID
2. Contrôlez les différences de protocole (http vs https)
3. Assurez-vous qu'il n'y a pas de barre oblique finale, sauf si elle est explicitement indiquée
4. Ajoutez les URLs de développement si vous testez en local

### Échecs d'authentification

**Erreur** : `access_denied` ou `unauthorized_client`

**Solution** :

1. Vérifiez que le Client ID et le Client Secret sont corrects
2. Vérifiez que l'application est activée dans Pocket ID
3. Assurez-vous que les scopes requis sont configurés
4. Vérifiez que l'utilisateur dispose des autorisations nécessaires

### Problèmes avec le point de terminaison de découverte

**Erreur** : Impossible de récupérer la configuration OIDC

**Solution** :

1. Vérifiez que votre serveur Pocket ID est accessible
2. Vérifiez que le point de terminaison de découverte (`/.well-known/openid-configuration`) est disponible
3. Assurez-vous que les certificats SSL sont valides
4. Vérifiez la connectivité réseau et les règles de pare-feu

## Bonnes pratiques de sécurité

### Gestion des identifiants

- **Stockage sécurisé** : Gardez le Client Secret sécurisé et ne le committez jamais dans un système de gestion de version
- **Rotation régulière** : Renouvelez périodiquement le Client Secret
- **Variables d'environnement** : Stockez les identifiants dans des variables d'environnement
- **Surveillance des accès** : Examinez régulièrement les journaux d'authentification

### Considérations pour la production

- **HTTPS obligatoire** : Utilisez toujours HTTPS en production
- **Certificats valides** : Assurez-vous que les certificats SSL sont valides
- **Mises à jour régulières** : Maintenez votre serveur Pocket ID à jour
- **Stratégie de sauvegarde** : Effectuez des sauvegardes régulières de la configuration Pocket ID
