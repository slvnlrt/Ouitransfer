## Mettre une star au projet

Mettre une star au dépôt augmente sa visibilité sur GitHub et aide d'autres personnes à le découvrir.

### Comment mettre une star

1. Rendez-vous sur le [dépôt OUITRANSFER](https://github.com/slvnlrt/ouitransfer)
2. Cliquez sur le bouton **Star** en haut à droite de la page

![Bouton Star](/assets/v1/sponsor/star-btn.png)

Le bouton passe à "Starred" pour confirmer votre action.

![Starred](/assets/v1/sponsor/starred-button.png)

Vous retrouverez tous vos dépôts favoris sous **Your stars** dans le menu de votre profil GitHub.
