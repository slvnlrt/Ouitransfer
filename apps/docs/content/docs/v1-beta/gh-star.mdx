## Star the project

Starring the repository increases its visibility on GitHub and helps other people discover it.

### How to star

1. Go to the [OUITRANSFER repository](https://github.com/slvnlrt/ouitransfer)
2. Click the **Star** button in the top-right area of the page

![Star Button](/assets/v1/sponsor/star-btn.png)

The button changes to "Starred" to confirm your action.

![Starred](/assets/v1/sponsor/starred-button.png)

You can find all your starred repositories under **Your stars** in your GitHub profile menu.
