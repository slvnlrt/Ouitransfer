## Soutenir le projet

Si OUITRANSFER vous est utile, vous pouvez soutenir son développement sur [Ko-fi](https://ko-fi.com/slvnlrt).

Votre soutien aide à couvrir les coûts d'infrastructure et finance le développement continu.

### Comment soutenir

1. Rendez-vous sur [ko-fi.com/slvnlrt](https://ko-fi.com/slvnlrt)
2. Choisissez un montant et finalisez le paiement

C'est tout. Merci de soutenir le développement open source.
