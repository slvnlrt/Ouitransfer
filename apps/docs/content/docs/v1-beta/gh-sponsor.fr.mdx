## Introduction

Sponsoriser un projet sur GitHub est un moyen puissant de soutenir son développement et d'assurer sa pérennité. Ce guide vous explique comment sponsoriser le projet **OUITRANSFER** via GitHub Sponsors.

En devenant sponsor, vous contribuez directement à la croissance du projet et à la qualité de celui-ci. Votre soutien permet notamment :

- Un développement continu et des corrections de bugs rapides
- La mise en œuvre de nouvelles fonctionnalités et améliorations
- La prise en charge des coûts d'hébergement et d'infrastructure
- La reconnaissance de l'investissement et du travail des développeurs
- La constitution d'une communauté de supporters qui valorisent le développement open source

---

## Prérequis du compte GitHub

Avant de pouvoir sponsoriser un projet, vous devez être connecté à votre compte GitHub. Si vous n'avez pas encore de compte, en créer un est gratuit et offre des avantages supplémentaires au-delà du sponsoring.

### Avantages d'un compte

Avoir un compte GitHub vous permet de :

- Suivre les mises à jour et les nouvelles versions du projet
- Signaler des problèmes et suggérer des améliorations
- Participer aux discussions du projet
- Accéder aux contenus réservés aux sponsors, le cas échéant
- Participer à la communauté GitHub au sens large

Si vous devez créer un compte, rendez-vous sur [la page d'inscription de GitHub](https://github.com/signup) et suivez le processus d'inscription.

## Accéder au dépôt

Une fois connecté à votre compte GitHub, rendez-vous sur le dépôt OUITRANSFER pour démarrer le processus de sponsoring.

### Accès direct

Visitez le dépôt OUITRANSFER directement : [https://github.com/slvnlrt/ouitransfer](https://github.com/slvnlrt/ouitransfer)

### Méthodes alternatives

Vous pouvez également trouver le dépôt en :

- Recherchant "OUITRANSFER" dans la barre de recherche GitHub
- Cherchant le dépôt appartenant à **Burger&Cie**
- Y accédant via la page de profil de Burger&Cie

### Actions supplémentaires sur le dépôt

Pendant que vous êtes sur la page du dépôt, vous pouvez également :

- **Mettre une star** au dépôt pour témoigner votre soutien
- Le **surveiller** (Watch) pour recevoir des notifications sur les mises à jour
- Le **forker** si vous souhaitez contribuer au code

## Initier le sponsoring

Le processus de sponsoring commence par la localisation et le clic sur le bouton Sponsor de la page du dépôt.

### Trouver le bouton Sponsor

Sur la page du dépôt OUITRANSFER, vous trouverez un bouton **Sponsor** bien visible dans la section supérieure de la page. Ce bouton est généralement affiché dans une couleur distincte pour assurer sa visibilité.

![OUITRANSFER Sponsor Button](/assets/v1/sponsor/sponsor-btn.png)

### Accès rapide

**Conseil** : Si vous avez déjà sponsorisé des projets, vous pouvez accéder directement à votre tableau de bord de sponsoring via votre profil GitHub, dans la section "Sponsoring".

## Choisir votre niveau de sponsoring

GitHub Sponsors propose des options de sponsoring flexibles pour s'adapter à différents budgets et préférences.

### Options de sponsoring personnalisées

GitHub Sponsors vous permet de sponsoriser le projet avec **un montant personnalisé à partir de 1 $** :

1. **Saisir un montant personnalisé** : Cherchez l'option permettant d'entrer un montant de sponsoring personnalisé
2. **Choisir votre montant** : Sélectionnez le montant qui vous convient (par exemple, 1 $, 5 $, 10 $ ou plus)
3. **Sélectionner la fréquence de facturation** : Choisissez entre un sponsoring **mensuel** récurrent ou un **paiement unique**
4. **Envisager les options annuelles** : Certains projets proposent des plans de sponsoring annuels simplifiés
5. **Consulter les avantages par palier** : Vérifiez les éventuels avantages spéciaux disponibles selon les niveaux de sponsoring

![Sponsor Page Example](/assets/v1/sponsor/sponsor-page.png)

### Recommandations de sponsoring

- **Sponsoring mensuel** : Offre un soutien régulier pour le développement continu
- **Sponsoring ponctuel** : Idéal pour exprimer votre reconnaissance pour des fonctionnalités ou des versions spécifiques
- **Paliers supérieurs** : Peuvent inclure des avantages supplémentaires tels qu'un accès anticipé ou une communication directe

---

## Finaliser votre sponsoring

Après avoir sélectionné votre montant de sponsoring et vos préférences de facturation, vous passerez au processus de paiement.

### Processus de paiement

1. **Vérifier votre sélection** : Confirmez le montant de votre sponsoring et la fréquence de facturation
2. **Saisir les informations de paiement** : Renseignez vos coordonnées bancaires comme demandé
3. **Finaliser la transaction** : Suivez le processus de paiement sécurisé de GitHub
4. **Confirmation** : Recevez la confirmation de votre sponsoring

Une fois le processus terminé, vous deviendrez officiellement **sponsor d'OUITRANSFER** et rejoindrez notre communauté de supporters.

## L'impact de votre sponsoring

Comprendre l'importance du sponsoring illustre la valeur de votre contribution à l'écosystème open source.

### Pérennité du projet

**Maintenance à long terme** : Votre sponsoring contribue à garantir que le projet reste activement maintenu et soutenu dans la durée.

**Soutien à l'innovation** : Le soutien financier donne aux développeurs la liberté d'expérimenter de nouvelles idées et de mettre en œuvre des fonctionnalités innovantes.

**Reconnaissance tangible** : Le sponsoring représente un moyen concret d'exprimer votre gratitude pour l'investissement et le travail des développeurs.

**Reconnaissance communautaire** : De nombreux projets reconnaissent publiquement leurs sponsors, en vous mentionnant éventuellement dans la documentation ou sur les sites du projet.

**Croissance de l'open source** : Votre soutien contribue à l'écosystème open source plus large, en aidant des projets précieux à prospérer et à se développer.

## Expérience post-sponsoring

Après être devenu sponsor, vous bénéficierez d'avantages supplémentaires et d'une reconnaissance au sein de la communauté OUITRANSFER.

### À quoi s'attendre

Une fois votre sponsoring confirmé :

1. **Confirmation par e-mail** : Vous recevrez un e-mail de confirmation de GitHub détaillant votre sponsoring
2. **Reconnaissance en tant que sponsor** : Votre nom sera ajouté à notre liste de sponsors et aux remerciements
3. **Contenu exclusif** : Accès aux mises à jour, informations et actualités du projet réservées aux sponsors
4. **Accès communautaire** : Invitation à rejoindre notre salon Discord privé pour les sponsors
5. **Accès anticipé** : Priorité d'accès aux nouvelles fonctionnalités et versions bêta, le cas échéant

### Avantages continus

En tant que sponsor, vous faites partie d'une communauté exclusive qui :

- Reçoit des mises à jour régulières sur le développement du projet
- A la possibilité de contribuer à l'orientation du projet
- Est reconnue pour son soutien au développement open source
- Bénéficie d'un support prioritaire, le cas échéant
