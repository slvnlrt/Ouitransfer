## Sponsoriser le projet

Si OUITRANSFER vous est utile, vous pouvez soutenir son développement via [GitHub Sponsors](https://github.com/sponsors/slvnlrt).

Votre soutien aide à couvrir les coûts d'infrastructure et finance le développement continu.

### Comment sponsoriser

1. Rendez-vous sur le [dépôt OUITRANSFER](https://github.com/slvnlrt/ouitransfer)
2. Cliquez sur le bouton **Sponsor** en haut de la page

![Bouton Sponsor](/assets/v1/sponsor/sponsor-btn.png)

3. Choisissez un montant (à partir de 1 $) et la fréquence de facturation (mensuel ou ponctuel)

![Page Sponsor](/assets/v1/sponsor/sponsor-page.png)

4. Finalisez le paiement via le processus sécurisé de GitHub

C'est tout. Merci de soutenir le développement open source.
