## Core components

### Frontend application (apps/web)

**Technology stack:**

- Next.js 15 (App Router)
- React 19
- TypeScript
- Tailwind CSS 4
- shadcn/ui components
- next-intl for internationalization
- TanStack Query v5 for server state management

OUITRANSFER.'s frontend is built with **Next.js 15**, using the App Router and Server Components for performance, scalability, and flexibility. The structure is modular and feature-based, keeping things easy to evolve as the product grows. UI logic runs on **React 19**, and **TypeScript** adds type safety that prevents a lot of silent bugs. Styles are handled with **Tailwind CSS 4**, letting us build clean, responsive interfaces quickly. For components, we rely on **shadcn/ui**, a headless component library built with Radix UI and Tailwind — it's fast, accessible, and fully customizable.

Internationalization is handled by **next-intl**, which integrates perfectly with Next.js routing. It supports locale-aware routes, per-page translation loading, and plural rules, all without any extra client-side bloat. It's flexible, lightweight, and great for apps with multilingual audiences.

The frontend is organized with:

- A **components-based architecture** for modular UI
- **Custom hooks** to isolate logic and side effects
- A **route protection system** using JWT verification via `jose` at the Edge (Next.js middleware)
- A **file management interface** integrated with the backend
- **Folder support** for organizing files hierarchically
- A **reusable modal system** used for file actions, confirmations, and more
- **Dynamic, locale-aware routing** using next-intl

### Backend service (apps/server)

**Technology stack:**

- Fastify 5
- Node.js 24
- SQLite + Prisma ORM
- S3-compatible object storage (RustFS built-in or external S3)
- Zod schemas via `fastify-type-provider-zod`

The backend is built on **Fastify 5**, a blazing-fast web framework for Node.js. It's lightweight, modular, and optimized for high performance. Every route is validated using **Zod schemas** (via `fastify-type-provider-zod`), which keeps the API consistent, secure, and fully type-safe. Auth flows are built using JWTs stored in HTTP-only cookies, and everything from file uploads to token-based sharing goes through this layer.

Data is stored in **SQLite**, which handles user info, file metadata, session tokens, and more. For file storage, the system uses **S3-compatible object storage** — RustFS is bundled as the default storage container, and external S3 providers can be enabled with `ENABLE_S3=true`. We use **Prisma** as our ORM to simplify database access — it gives us type-safe queries and easy-to-read code.

Key features include:

- **Authentication/authorization** with JWT + cookie sessions, CSRF protection, and 2FA
- **File management logic** including uploads, deletes, renames, and folders
- **Storage operations** to handle file organization, usage tracking, and cleanup via S3-compatible APIs
- A **share system** that generates tokenized public file links
- Zod-based request validation for all endpoints (fully type-safe, no runtime surprises)
- Prisma models that keep the database logic predictable and type-safe
- **Audit logging** for security-sensitive operations

### Shared packages

**`packages/shared`** — Shared utilities used by both the server and web apps:

- MIME-type detection and mapping
- Consumed via subpath exports (`@ouitransfer/shared/mime-types`)

**`packages/config`** — Shared TypeScript configuration presets:

- `base`, `server`, and `nextjs` tsconfig presets
- Ensures consistent TypeScript settings across the monorepo

### Documentation (apps/docs)

**Technology stack:**

- Fumadocs
- MDX (Markdown + JSX)
- React-based components

The docs are built using **Fumadocs**, a modern documentation system built on top of Next.js. It uses **MDX**, so you can mix Markdown with interactive React components — perfect for developer tools and open-source projects. Pages are fast, versionable, and easy to customize. The goal is to keep the documentation as close to the codebase as possible, using shared components where needed and reusing UI patterns directly from the app.

It supports sidebar navigation, keyboard shortcuts, dark mode, and even interactive demos or UI previews. The file tree you see above, for example, is powered by a real React component from the docs.

- Built with **Fumadocs**, powered by Next.js
- Supports **MDX** and full React component embedding
- Ideal for technical docs and live code samples
- Styled using the same Tailwind setup from the main app

### Infrastructure

OUITRANSFER. is fully containerized using **Docker** with a **3-container architecture**: `storage` (RustFS S3-compatible object storage), `server` (Fastify API server with embedded SQLite), and `web` (Next.js frontend). With `docker-compose`, the whole stack spins up locally with a single command. Startup ordering is managed automatically via healthcheck-based `depends_on` conditions (`storage` → `server` → `web`).

Volumes are used to persist data, and containers are networked together so that all services can communicate securely.

- **3-container Docker architecture**: `ouitransfer-storage`, `ouitransfer-server`, `ouitransfer-web`
- Configurable through `.env` and compose overrides
- Local volumes and named networks
- Healthcheck-based startup ordering
- Easy to deploy and scale on any container-compatible infrastructure

### Monorepo tooling

The monorepo is managed with **pnpm 10.6.0** workspaces and **Turborepo** for build orchestration. Key tooling:

- **Biome** — unified linter and formatter (replaces ESLint + Prettier)
- **Vitest** — unit and integration testing
- **Playwright** — end-to-end testing
- **Lefthook** + **commitlint** — Git hooks and conventional commit enforcement
- **pnpm catalogs** — shared dependency version management across workspace packages
- **`just`** — task runner (`just --list` for all available recipes)

## Key features

### File management

Files are at the heart of OUITRANSFER. Users can upload files via the frontend, and they're stored in S3-compatible object storage (RustFS by default). Users can also create folders to organize files. The backend handles metadata (name, size, type, ownership), and also handles deletion, renaming, and public sharing. Every file operation is tracked, and all actions can be scoped per user.

- Upload/download with instant feedback
- Create and organize files in folders
- File previews, type validation, and size limits
- Token-based sharing system
- Disk usage tracking by user

### User system

Authentication is done through secure JWTs, stored in HTTP-only cookies for safety. Signup and login flows are simple and fast, and user info is kept in sync across the frontend and backend.

- Cookie-based session management with refresh token rotation
- Role support and admin access
- Profile updates and password reset flows
- Two-factor authentication (TOTP, RFC 6238)
- Logged-in user state handled via TanStack Query

### Storage system

The system uses **S3-compatible object storage** for all file operations. **RustFS** is bundled as the default storage container — no external service required. For users who need cloud storage or additional scalability, the architecture supports any S3-compatible provider via `ENABLE_S3=true`. The backend tracks usage, handles cleanup of orphaned files, and ensures that every file in storage has a matching database record.

- S3-compatible object storage (RustFS built-in by default)
- External S3 support (AWS S3, Backblaze B2, Cloudflare R2, etc.) via `ENABLE_S3=true`
- Upload validation and automatic cleanup
- Usage tracking and quotas (per user or global)
- Presigned URLs for secure, time-limited direct uploads and downloads

### Internationalization

OUITRANSFER. supports multiple languages using **next-intl**, which is deeply integrated into the routing system. It loads only the necessary translations per route, supports nested namespaces, and makes it easy to keep things organized even at scale.

- Per-locale routing (`en-US`, `pt-BR`, etc.) — 23 languages supported
- Translation loading by namespace/page
- Full pluralization and formatting support
- Easy translation management via JSON files
