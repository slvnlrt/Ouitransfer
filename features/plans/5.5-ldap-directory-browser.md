# 5.5 — LDAP Directory Browser Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Dispatch agents **sequentially, one at a time** (CLAUDE.md Rule 0).

**Goal:** Let an admin bind once and pick LDAP DNs from the live directory instead of typing them — Base DN via RootDSE auto-detect + a lazy container tree, Sync Group via a search box. `bindDn` stays free-text.

**Spec:** [`features/specs/5.5-ldap-directory-browser.md`](../specs/5.5-ldap-directory-browser.md) — all design decisions and the folded-in review findings (C-1, I-1..I-4, M-1..M-6) live there.

**Architecture:** Two new admin-gated POST routes (`/admin/ldap/browse`, `/admin/ldap/search-groups`) backed by three new `LdapClient` methods (`readRootDse`, `browseContainers`, `searchGroups`) and a shared masked-password resolver. The web side adds two dialog components (`ldap-directory-browser`, `ldap-group-search`) wired into the existing `ldap-config-form` via "Browse" buttons, plus the mirrored HTTP types.

**Tech Stack:** Fastify 5 (ESM, `.js` imports), `ldapts@8.1.8`, Zod v4 + `@fastify/type-provider-zod`, Prisma; React 19, Next.js 15, TanStack Query, next-intl, shadcn/ui Dialog, Vitest + Testing Library.

**Security non-negotiables (from spec):** every bind goes through `LdapClient.connect` → `assertLdapTargetAllowed`; group query composed as `ldapts` **filter objects** (never string-interpolated, C-1); all searches `sizeLimit`-capped; failures genericized except `LDAP_*` config errors; routes admin-gated, no setup bypass.

## Lot 1 — Server (backend contract + tests)

> Lands the API contract and the `LdapDirectoryNode` shape that Lot 2 mirrors. Must be fully green before Lot 2.

### Task 1.1: DTO + constants + masked-password resolver
**Files:** `dto.ts`, `constants.ts` (new), `bind-password.ts` (new), `routes.ts` (import only)
- [ ] Hoist `MASKED_PASSWORD` from `routes.ts:16` into `constants.ts`; import it back in `routes.ts` (no behavior change, no duplicate string). Add `BROWSE_SIZE_LIMIT = 200`, `GROUP_SEARCH_SIZE_LIMIT = 50`.
- [ ] `dto.ts`: add `LdapConnectionFieldsSchema` (`serverUrl` min 1, `bindDn` min 1, `bindPassword: z.string()` — empty/masked allowed, `useTls` default true, `tlsSkipVerify` default false). Add `LdapBrowseSchema` (= connection fields + `baseDn: ldapDn.optional()`) and `LdapSearchGroupsSchema` (= connection fields + `searchBase: ldapDn` + `query: z.string().min(1).max(256)`).
- [ ] `bind-password.ts`: `resolveBindPassword(body)` → returns plaintext. If `bindPassword` is empty or `MASKED_PASSWORD`: load stored config; if none → throw `AppError(400, …, "LDAP_BIND_PASSWORD_REQUIRED")`; else `decrypt()` and on failure (missing/invalid `ENCRYPTION_SECRET`) throw `AppError(400, …, "LDAP_ENCRYPTION_UNAVAILABLE")`. Otherwise return the supplied value.
- [ ] Unit tests for `resolveBindPassword`: typed password passthrough, masked→stored decrypt, no-stored-config error, decrypt-failure error.

### Task 1.2: `LdapClient` directory methods
**Files:** `ldap.client.ts`, client unit tests
- [ ] Export `LdapDirectoryNode = { dn; name; type: "ou"|"container"|"domain"|"group"; hasChildren }`.
- [ ] `readRootDse()`: base `""`, scope `base`, attrs `["namingContexts","defaultNamingContext"]`. Return filtered `namingContexts` (drop empty strings) + `defaultNamingContext ?? null`.
- [ ] `browseContainers(baseDn)`: scope `one`, objectClass filter (organizationalUnit/container/domainDNS/builtinDomain) as filter **objects** (`OrFilter`/`EqualityFilter`), attrs `["ou","cn","name","objectClass"]`, `sizeLimit` `BROWSE_SIZE_LIMIT`. Map → nodes (`name` = ou||cn||name; `type` from objectClass; `hasChildren=true`), sort by `name`.
- [ ] `searchGroups(searchBase, query)`: scope `sub`, filter `AndFilter([EqualityFilter(objectClass=group), OrFilter([SubstringFilter(cn, any:[query]), SubstringFilter(sAMAccountName, any:[query])])])`, attrs `["cn","name"]`, `sizeLimit` `GROUP_SEARCH_SIZE_LIMIT`. Return `{ nodes, truncated }` where `truncated` = entries reached the cap.
- [ ] **C-1 unit test:** a `query` of `*()\` is passed as a `SubstringFilter` value (object), asserted via the constructed filter — never interpolated into a filter string.
- [ ] Unit tests: RootDSE empty-NC filtering + null `defaultNamingContext`; container objectClass mapping/sorting on AD-shaped fixtures; sizeLimit + truncation.

### Task 1.3: Routes
**Files:** `routes.ts`, route integration tests
- [ ] `POST /admin/ldap/browse` (admin pre-validation): body `LdapBrowseSchema`. Resolve password; `connect`; no `baseDn` → `readRootDse` → `{ nodes: namingContexts as domain roots, defaultBaseDn }`; with `baseDn` → `browseContainers` → `{ nodes, defaultBaseDn: null }`. try/catch → only `LDAP_*` surfaced else generic; `disconnect` in `finally`.
- [ ] `POST /admin/ldap/search-groups` (admin pre-validation): body `LdapSearchGroupsSchema` → `{ groups, truncated }`. Same error/disconnect discipline. **No audit log, no rate limit** (Decisions 4–5).
- [ ] Integration (`app.inject()`): admin gate (401/403), masked vs typed password (incl. no-config + `ENCRYPTION_SECRET`-unset → surfaced `LDAP_*`), DN/query validation (400), generic error on bind failure (no topology leak), truncation flag, naming-context vs children branches.
- [ ] **Run `pnpm --filter @ouitransfer/server test` + type-check + lint — all green before Lot 2.**
