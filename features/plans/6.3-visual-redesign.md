# 6.3 Visual Redesign — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the generic green+frosted-glass identity with a professional deep-indigo theme that feels smart, sober, corporate yet has visual wow factor.

**Architecture:** CSS-first redesign — most changes are in `globals.css` (color tokens) and component-level Tailwind classes. No structural HTML changes. The customization system (ThemeColorProvider) is preserved.

**Tech Stack:** Tailwind CSS 4 (OKLCH colors), motion (framer-motion), shadcn/ui primitives, Inter font.

## Task 2: Background Effect Redesign

**Files:**
- Modify: `apps/web/src/components/ui/background-lights.tsx`
- Modify: `apps/web/src/app/login/components/static-background-lights.tsx`

**Goal:** Replace the breathing green blobs with a sophisticated gradient mesh. Slower, more subtle, indigo-tinted.

- [ ] **Step 1: Rewrite BackgroundLights**

Replace with a gradient mesh pattern using 3 overlapping blobs with very slow drift:

```tsx
"use client";

import { motion } from "motion/react";

export function BackgroundLights() {
  return (
    <div className="absolute inset-0 -z-10 overflow-hidden">
      {/* Primary indigo blob — top left */}
      <motion.div
        animate={{
          x: [0, 30, 0],
          y: [0, -20, 0],
          opacity: [0.25, 0.4, 0.25],
        }}
        className="absolute -top-[30%] -start-[20%] w-[80%] h-[80%]"
        style={{
          background: `radial-gradient(ellipse at center, oklch(from var(--primary) l c h / 0.12) 0%, transparent 70%)`,
        }}
        transition={{
          duration: 20,
          repeat: Infinity,
          ease: "easeInOut",
        }}
      />
      {/* Secondary deeper blob — bottom right */}
      <motion.div
        animate={{
          x: [0, -20, 0],
          y: [0, 30, 0],
          opacity: [0.2, 0.35, 0.2],
        }}
        className="absolute -bottom-[20%] -end-[10%] w-[70%] h-[70%]"
        style={{
          background: `radial-gradient(ellipse at center, oklch(from var(--primary) calc(l - 0.1) c h / 0.1) 0%, transparent 65%)`,
        }}
        transition={{
          duration: 25,
          repeat: Infinity,
          ease: "easeInOut",
          delay: 8,
        }}
      />
      {/* Accent warm glow — center, very subtle */}
      <motion.div
        animate={{
          opacity: [0.05, 0.12, 0.05],
        }}
        className="absolute top-[20%] start-[30%] w-[50%] h-[50%]"
        style={{
          background: `radial-gradient(ellipse at center, oklch(0.75 0.12 75 / 0.08) 0%, transparent 60%)`,
        }}
        transition={{
          duration: 15,
          repeat: Infinity,
          ease: "easeInOut",
          delay: 4,
        }}
      />
    </div>
  );
}
```

Key changes:
- 3 blobs instead of 2 (more complex mesh)
- Very slow drift (20-25s cycles vs 5s — premium feel)
- Translate movement instead of scale (more organic)
- Lower max opacity (0.35-0.4 vs 0.5 — more subtle)
- Added warm accent blob (gold hue 75) for visual interest
- Uses CSS relative color syntax `oklch(from var(--primary) ...)` to respect customization
