# 6.2 — UI Code Quality Fixes

## Goal

Fix all issues identified in the 6.1 UI audit. This is the remediation phase — making the codebase clean and consistent before the visual redesign.

## Scope

Determined by 6.1 audit output. Expected categories:
- Extract reusable components (duplicated UI patterns → shared primitives)
- Unify styling patterns (inconsistent class usage, magic values → design tokens)
- Fix component structure (split oversized files, clarify naming)
- Remove dead/redundant UI code
- Fix accessibility issues not already covered by Phase 4

## Depends On

- 6.1 UI audit must be complete

## Deliverable

- All fixes implemented and committed
- Full test suite passing (`pnpm --filter web test`)
- Type-check passing (`pnpm --filter web run type-check`)
- Review in `features/reviews/6.2-ui-fixes-review.md`

## Open Questions

- Batch strategy will be determined based on 6.1 findings
