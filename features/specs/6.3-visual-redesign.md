# 6.3 — Visual Redesign

## Goal

Give Ouitransfer a new visual identity after the project takeover. The redesign signals a fresh start and a professional product.

## Design Direction

- **Smart, sober, corporate** — professional look that inspires trust
- **Wow factor** — subtle animations, refined transitions, attention to micro-interactions
- **Not boring** — the design should feel premium and polished, not generic enterprise
- **Color palette**: Replace the current default green with a new primary color (TBD — explore blues, deep teals, or sophisticated neutrals)
- **Typography**: Review current Outfit font usage; ensure hierarchy is clear
- **Spacing & rhythm**: Consistent use of Tailwind spacing scale
- **Dark mode**: Must remain polished (currently functional but may need refinement)

## Scope

- Global color palette (CSS variables / Tailwind theme)
- Component visual refresh (buttons, cards, inputs, modals, dropdowns)
- Page layouts (dashboard, settings, share pages, admin)
- Landing page (already redesigned post-Phase 9 — may need palette update)
- Login / registration flow
- Navigation (sidebar, topbar)
- Loading states, empty states, error states
- Micro-animations (hover effects, transitions, page transitions)

## Out of Scope

- Structural HTML changes (handled in 6.2)
- New features (handled in 5.x track)
- Backend changes

## Depends On

- 6.2 UI fixes must be complete (clean codebase before restyling)

## Open Questions

1. **Primary color** — What replaces the green? Need to explore options and decide.
2. **Logo** — Does the app logo need updating to match the new palette?
3. **Gradient usage** — Subtle gradients for headers/cards or flat design only?
4. **Animation library** — Continue using `motion` (framer-motion) or lighter approach with CSS transitions?
5. **shadcn/ui theme** — Full custom theme or adapt an existing shadcn theme?

## Deliverable

- Updated Tailwind/CSS theme configuration
- All pages visually refreshed
- Dark mode verified
- Before/after screenshots (optional but useful)
- Review in `features/reviews/6.3-redesign-review.md`
